# מציירים בחוויה עם מרימי — דף נחיתה

דף נחיתה סטטי (HTML / CSS / JS) לחוגי הציור בזום של מרימי כהן. בלי דטה בייס, מוכן לפריסה ב-Vercel או ב-GitHub Pages.

- `index.html`, `styles.css`, `app.js` — הדף
- `assets/` — תמונות מותאמות, אייקונים וגלריה (`gallery.json`)
- `vercel.json` — הגדרות פריסה

קישור התשלום נקבע ב-`window.SITE.payUrl` בראש `index.html`.
